プライバシーポリシー（Yukimaki Upload Tool）

制定日：2026年11月21日

1. 取得する情報と使い道

本ツールは、Google の OAuth 認証で、運営者本人の YouTube アカウントへのアクセス許可を受けます。使い道は、運営者のチャンネルへの動画のアップロードと、公開日時・タイトル・説明・サムネイル・再生リスト・字幕・コメントの設定だけです。

2. 保存の場所

認証で受け取るトークンは、運営者のパソコンの中にだけ保存します。外部のサーバーには保存しません。

3. 第三者への提供

取得した情報を、第三者に提供・販売・共有することはありません。広告にも使いません。

4. YouTube と Google のポリシー

本ツールは YouTube API サービスを使っています。利用には YouTube 利用規約 が適用され、データの扱いは Google プライバシーポリシー に従います。

5. アクセス許可の取り消し

許可はいつでも、Google アカウントの サードパーティのアプリとサービス から取り消せます。取り消すと、本ツールは YouTube にアクセスできなくなります。

6. データの削除

本ツールが保存するのは、運営者のパソコンの中の認証トークンだけです。YouTube から取得したデータ（チャンネル名や動画の ID など）は、処理の確認に使うだけで、30日を超えて保存しません。アクセス許可を取り消したときや、運営者が利用をやめたときは、パソコンの中のトークンをすぐに削除します。削除の依頼は、下のお問い合わせ先から受け付けます。

7. お問い合わせ

GitHub（github.com/iyashiweek）からご連絡ください。

Privacy Policy (Yukimaki Upload Tool)

Effective date: November 21, 2026

Information and use. This tool uses Google OAuth to receive permission to access the owner's own YouTube account. It is used only to upload videos to the owner's channel and to set the publish time, title, description, thumbnail, playlist, captions and comments.

Storage. OAuth tokens are stored only on the owner's computer, not on any external server.

Sharing. No data is provided, sold or shared with third parties, and none is used for advertising.

YouTube and Google policies. This tool uses YouTube API Services. Use is subject to the YouTube Terms of Service, and data is handled under the Google Privacy Policy.

Revoking access. Access can be revoked at any time from Third-party apps & services in your Google Account.

Data deletion. The only thing this tool stores is the OAuth token on the owner's computer. Data obtained from YouTube (such as channel names and video IDs) is used only to confirm each operation and is not stored for more than 30 days. When access is revoked or the owner stops using the tool, the token is deleted from the computer immediately. Deletion requests can be sent to the contact below.

Contact. Please reach us via GitHub (github.com/iyashiweek).
