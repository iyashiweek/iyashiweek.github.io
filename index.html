Yukimaki Upload Tool

ユキマキの動画投稿ツールは、運営者が自分の YouTube チャンネルに、自分で制作した動画をアップロード・予約投稿するための個人用ツールです。

YouTube Data API を使って、動画のアップロード、公開日時の予約、タイトル・説明・サムネイル・再生リスト・字幕の設定を行います。運営者本人だけが使い、第三者にサービスとして提供するものではありません。

English

Yukimaki Upload Tool is a personal tool that the owner uses to upload and schedule videos they created to their own YouTube channel. It uses the YouTube Data API to upload videos and set the publish time, title, description, thumbnail, playlist and captions. It is used only by the owner and is not offered as a service to others.
